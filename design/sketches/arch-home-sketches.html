Sketches · Home §3 "Behind the Scenes" — matching the inner page

Four ways to tease the machine

The inner Architecture page draws the system as four isometric sheets pulled apart in space, wires over them, the retrain flywheel in ochre. Home §3 is one screen in a six-section scroll, so it can't take over the page the way the inner one does — it previews that drawing as a still that reveals on arrival, and ends on the one link in. These are four compositions of the same sheets. Pick one and I'll build it into transition-prototype.html, replacing the ring.

Shared by all four. The four plane fills, the Bodoni plane names, the ochre flywheel, and the brand logos from today's ring (Lambda, PyTorch, Docker…) — regrouped onto the inner page's four planes. The copy stays the demo's: "Behind the Scenes" / "From strokes to prediction" / "Explore the full architecture →".
The drawings below are static stills (no entrance), so the composition is what you're judging. The laptop board is what matters for the choice; phones get tuned on build.
H1

The overview still

The inner page's opening pose, frozen: the four sheets stacked and pulled apart, every part drawn, all four wires faint, the flywheel wire ochre. The reading column and the link sit to the left, exactly where the inner page keeps them on a laptop. Tightest match — the teaser is a literal still of where the link leads. Logos run as a legend below.

H2

The exploded fan

The four sheets spread across the width on a shallow diagonal, each carrying its plane name and its own tools. Poster-like; the logos sit on the sheets, not in a legend.

Hero sheet, with depth

Serving — the always-on front door the visitor actually touches — stands in front at full size with its tools; the other three fan behind it, receding and paler, with the flywheel threading them.
